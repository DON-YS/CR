08 — DEPLOYMENT

GITHUB PAGES

SHAHEEN APEX is designed as a static website that can be published directly through GitHub Pages.

Deployment procedure:

1. Upload "index.html" to the repository root.
2. Open repository Settings.
3. Navigate to Pages.
4. Select Deploy from a branch.
5. Choose "main".
6. Select "/ (root)".
7. Save and wait for deployment.

The website can then be accessed through its assigned GitHub Pages address.
